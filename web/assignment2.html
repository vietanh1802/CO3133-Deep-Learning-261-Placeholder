Assignment 2 · 11 November 2026

Underwater segmentation

Deep Learning on Large-Scale Data and Specialized Tasks.

Problem statement

The task is to label each pixel in an underwater photograph as water, a diver, marine life, vegetation, a robot, a wreck, a reef or the sea floor. We compare a model trained from scratch with a pretrained model, focusing on rare classes and object boundaries.

Dataset and EDA

SUIM pairs underwater photographs with colour-coded masks that label every pixel. Its varied scenes and uneven class frequencies let us compare segmentation quality on common and rare objects.

The eight classes are waterbody (BW), divers (HD), plants and sea-grass (PF), wrecks (WR), robots and instruments (RO), reefs and invertebrates (RI), fish and vertebrates (FV), and sea-floor and rocks (SR).

We resize images and masks to 320 × 240 pixels. The model assigns one of the eight classes to each pixel to produce a predicted mask.

Data quality and splits

The archive contains 1,635 image-mask pairs. Every file decodes and every image has a mask. We exclude 85 training-pool pairs whose masks contain colours outside the eight class codes. These include all 37 masks that are taller than their images.

Ten training-pool images duplicate official test images. We remove the training copies and retain all 110 test pairs, leaving 1,540 usable pairs.

The remaining training pool contains 55 duplicate groups covering 115 images. Duplicate groups stay together when we split the pool into training and validation, using seed 42 and each image's rarest class to balance the split. All eight classes appear in both sets.

Class balance and image sizes

Reefs occupy 35.64% of usable training-pool pixels, while robots occupy 0.56%. Only 69 training images and 17 validation images contain robots.

The 1,540 usable pairs span 11 image sizes. About 84% are 640 × 480 pixels. Resizing to 320 × 240 reduces detail in small objects and thin boundaries.

Colour and brightness by class

We compare colour and brightness across classes using photograph pixels grouped by their ground-truth labels. The plot uses 287 validation images resized to 240 × 320. Plants and reefs have broadly overlapping distributions, so colour alone may offer limited separation between these classes.

Methodology

We pair each photograph with its mask and resize both to 320 × 240 pixels, using bilinear interpolation for images and nearest-neighbour interpolation for masks. We decode mask colours into class labels and normalize images with ImageNet statistics. During training, we randomly flip each image and its mask together.

Both baseline configurations use cross-entropy over all eight classes. DeepLabV3 fine-tunes the backbone at a base learning rate of 0.0001 and its classifier at 0.001. BatchNorm running statistics remain fixed; its affine parameters and the rest of the network still train. U-Net uses one base learning rate of 0.001.

The checkpoint with the highest validation mIoU supplies the reported metrics. IoU and Dice are computed from confusion counts accumulated over the whole validation split, then averaged equally across all eight classes, including background. The reported convention assigns zero to an absent-class denominator and ignores no labels.

Experimental setup

Both baseline comparison runs use seed 42, the committed data split, 320 × 240 inputs, AdamW with weight decay 0.0001, float32 training, and a 40-epoch budget. The learning-rate schedule uses five warm-up epochs followed by cosine decay. Both accumulate gradients over four minibatches.

Experimental design

We run six comparisons. The five DeepLabV3 variants each change one factor of the reference configuration. The U-Net and DeepLabV3 comparison changes architecture, size and initialization together, so it cannot isolate the effect of pretraining. Only the loss comparison carries a hypothesis stated in advance, in our dataset proposal.

To judge whether a difference exceeds chance, we compare it with the variation between repeated training runs. The six DeepLabV3 configurations were trained twice with the same code, seed and GPU, and their mIoU differed by up to 0.97 points, most likely because some GPU operations are not deterministic. We report the second set of runs, whose checkpoints and records are complete, and treat smaller differences as indistinguishable.

On the test split, DeepLabV3 with cross-entropy exceeds the U-Net baseline by 31.52 percentage points in mIoU (25.11 points on validation), while using 5.1 times as many parameters. Each configuration was trained once, but this gap is far larger than the variation between repeated training runs.

The test scores of DeepLabV3 are 6.22 points higher than its validation scores, while those of U-Net differ by only 0.19 points. Two checks suggest a difference between the image sets rather than leakage. Test images are no closer to the training images than validation images are: the median difference-hash distance to the nearest training image is 15 bits for both splits. The median per-image mIoU is also similar, 57.7% on test and 54.4% on validation. Instead, the class mix differs: reefs appear in 53% of test images against 71% of validation images, and sea floor in 55% against 39%. With only 110 test images, comparisons between models on the same images are more informative than the absolute scores.

At epoch 40, U-Net records train/validation cross-entropy of 0.7400/0.7526, and both losses are still falling, so a longer schedule may help. The DeepLabV3 reference ends at 0.0846/0.9841: its validation loss is lowest at epoch 11 and then rises, yet its validation mIoU keeps improving and selects epoch 31. With CE + Dice, validation mIoU peaks at epoch 24 and finishes 1.32 points below that peak.

U-Net gets almost no plant or robot pixels right on either split. DeepLabV3 scores higher on every class on both splits and reaches 71.09% robot IoU on test, but plants remain difficult at 24.12%. Aggregate improvement therefore does not imply that every class is well segmented.

Our loss hypothesis was that adding Dice raises the IoU of robots, plants and wrecks without lowering mIoU. On validation, CE + Dice raises plant IoU by 2.93 points but lowers robot IoU by 2.38 and wreck IoU by 0.45, with a 0.23-point mIoU gain. The test split, used only as a check, shows the same pattern: plants +10.66, robots −2.22, wrecks −0.79 and mIoU +0.91. Since not all three classes improve, the hypothesis is not supported, and the overall change is smaller than the variation between repeated runs.

The larger pretrained model performs better in this observed comparison. Architecture and parameter count also change, so the result cannot establish how much improvement is caused by pretraining alone.

Controlled experiments

We use DeepLabV3-ResNet50 as the reference and change one factor per run: backbone freezing, horizontal flips, backbone depth, loss or input resolution. All six runs share seed 42, the same data split and 40 training epochs. All six runs use one RTX 4060 Ti with PyTorch 2.14.0 and CUDA 12.6. We use batches of four and accumulate four batches per update, giving an effective batch of 16.

We keep AdamW, weight decay 0.0001, backbone and head learning rates of 0.0001 and 0.001, five warm-up epochs and cosine decay fixed. BatchNorm running statistics also stay fixed. We select each checkpoint by its highest validation mIoU.

Our reference fine-tunes the full pretrained network with horizontal flips, cross-entropy and 320 × 240 inputs. For the half-resolution run, we resize output scores to 320 × 240 before assigning class labels. The combined loss weights cross-entropy and per-image macro soft Dice equally across all eight classes. We calculate differences against this reference, using the same effective batch of 16 throughout.

Two factors have a clear effect: fine-tuning the full network and keeping the original input resolution. Halving the input also lowers boundary mIoU from 30.07% to 26.52%. The other three variants change mIoU by at most 0.35 points, no more than the 0.35-point change we observed when retraining the reference with the same seed, so this single-seed study cannot show that flips, a deeper backbone or the Dice term help. We retain the full ResNet50 reference with cross-entropy as the simpler choice among the configurations with similar overall scores.

Error analysis

We most often confuse plants with reefs: DeepLabV3 labels 71.27% of plant pixels as reef. Small objects show a different failure: 11.46% of robot pixels are assigned to divers. The first confusion matrix below covers all 287 validation images.

Both confusions persist on the test split. There the reference assigns 43.39% of plant pixels to reef and 15.57% of robot pixels to divers, so the plant confusion is weaker than on validation but remains the largest error for that class.

Both models struggle at object boundaries. DeepLabV3 reaches 30.07% boundary mIoU against 64.34% in the interior. U-Net drops from 37.88% in the interior to 18.04% at boundaries.

Performance also varies across images. DeepLabV3 has a median per-image mIoU of 54.43%. Per-image scores average over classes present in each image, while the overall metric pools pixels across the split.

We selected the lowest-IoU plant and robot examples to inspect rare-class failures. When scores tie, we choose the largest labelled region, then the filename. Both selected classes have zero IoU.

Limitations

We trained each configuration with one seed, so we cannot estimate the spread between seeds. A repeated training run shows that this spread matters: retraining the six DeepLabV3 configurations with the same code, seed and GPU changed mIoU by up to 0.97 points and the IoU of a single class by up to 6.56 points (robots). The loss comparison even changed sign, from −0.13 points in the first run to +0.23 in the second. The U-Net and DeepLabV3 comparison also changes architecture, pretraining and hardware, so we cannot attribute the score difference to pretraining alone or compare their speed directly.

The test scores come from only 110 images whose class mix differs from validation. Only 12 test images contain robots and 20 contain plants, so the test IoU of these classes, including the effect of Dice, rests on few images. Resizing can remove small objects and thin boundaries, and plant segmentation remains weak. Duplicate filtering does not rule out related scenes across splits.

Conclusion

The pretrained DeepLabV3 configuration raises test mIoU from 36.75% to 68.27% and improves every class's IoU over the U-Net baseline on both splits. Adding Dice raises plant IoU but lowers robot and wreck IoU on both validation and test, so the experiment does not support our hypothesis. Together with the other controlled comparisons, these findings support full fine-tuning of ResNet50 with cross-entropy at the original training resolution.
