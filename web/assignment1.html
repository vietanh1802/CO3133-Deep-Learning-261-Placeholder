Problem Statement

We classify each 28-by-28 grayscale Fashion-MNIST image into one of ten clothing categories. The draft establishes a shared PyTorch pipeline and compares a linear classifier with a multilayer perceptron under the same split and evaluation protocol.

Dataset Description and EDA

Fashion-MNIST contains 60,000 official training images and 10,000 official test images. Every class has exactly 6,000 training examples, giving a maximum-to-minimum class ratio of 1.00. We reserve 6,000 training examples for validation using seed 42; the remaining 54,000 are used for training. Images are converted to float tensors, normalized to approximately [-1, 1], and training images receive a small random affine augmentation. The generated EDA figures are retained with the experiment artifacts:

Methodology

The current draft compares two flattened-pixel models. Linear maps 784 input values directly to ten logits. MLP uses hidden dimensions 256 and 128 with ReLU and dropout 0.2 before the shared ten-class head. Both optimize cross-entropy directly from logits. CNN, GRU, and Transformer results will be added for the final submission.

Experimental Setup

Both draft models use Adam, learning rate 0.001, batch size 128, five epochs, and seed 42. Training ran on Apple MPS; reported inference timings were measured on CPU. The selected checkpoint is the epoch with the lowest validation loss. These are preliminary single-seed runs.

Comparison and Discussion

The MLP improves test accuracy by 5.86 percentage points and macro-F1 by 0.0563, indicating that nonlinear combinations of flattened pixels are useful. It requires roughly thirty times as many parameters and has slower inference. Neither model uses spatial locality, so this draft does not yet establish the benefit of convolutional or sequence-oriented inductive biases.

Error Analysis

Both preliminary models struggle most with visually similar upper-body garments. Shirt has the lowest test accuracy: 35.3% for the linear model and 41.8% for the MLP. The linear model most often maps Shirt to Coat or Pullover; the MLP most often maps it to T-shirt/top or Pullover. Pullover and Coat are also confused in both directions. This is consistent with both encoders flattening away explicit spatial locality.

The saved qualitative evidence separates representative correct predictions, confident errors, and uncertain errors. Some mistakes exceed 99% confidence, so the current models' confidence should not be treated as calibrated.

Limitations and Conclusion

These are five-epoch, single-seed draft results and should not be interpreted as the final architecture comparison. The final study must add CNN, GRU, and Transformer runs, repeated seeds where feasible, and a complete inductive-bias discussion.
