\section{Implementation results}
\label{sec:results}

\subsection{Test performance and model size}
\label{sec:quantitative}
The main comparison uses the official Fashion-MNIST test set of 10,000 images.
All six models train for 50 epochs with seed 42. Each checkpoint minimizes
validation loss; test performance does not enter checkpoint selection.
\input{Tables/comparison}
\input{Tables/checkpoint_summary}

CNN reaches 92.59\% accuracy and 0.9261 macro-F1. The remaining accuracies are Transformer 90.43\%, GRU 89.88\%, LSTM 89.52\%, MLP 87.18\%, Linear 77.05\%.
CNN exceeds Transformer accuracy by 2.16 percentage points, with 421,738 versus 1,191,050 parameters. These values describe the tested configurations and one seed.

\subsection{Learning behavior}
The CNN reaches its minimum validation loss at epoch 42, 0.1948.
The learning curves compare all six models under the same epoch budget.
Training applies augmentation and model-specific regularization; validation
does not. A lower validation loss than training loss alone does not diagnose
underfitting.

\subsection{Per-class performance and error analysis}
\label{sec:errors}
Class recall is the fraction of correctly classified images within a class.
Each Fashion-MNIST test class contains 1,000 images.
\input{Tables/error_recall}

CNN Shirt recall is 79.5\%, compared with 62.1\% for MLP. CNN Coat and Pullover recalls are 86.3\% and 90.1\%. It assigns 81 Shirt images to T-shirt/top and 61 Coat images to Pullover.
Errors between T-shirt/top, Pullover, Coat, and Shirt account for 507 of its 741 errors, 68.4\%. Both the true and predicted labels must belong to that group for an error to count. Similar outlines are a possible explanation, but these observations do not establish the cause.

\subsection{Predictions on shared images}\label{sec:qualitative}
CNN correctly classifies 775 images that MLP misclassifies. MLP correctly classifies 234 images that CNN misclassifies. Both err on 507 images and both classify 8484 correctly. The disagreement difference is 541 images, consistent with the 5.41 percentage-point accuracy difference. Neither model contains all the other model's correct predictions.
The shared examples take the first two official test indices in each of three
categories: CNN correct and MLP wrong, both wrong, and MLP correct and CNN wrong.
Indices are zero-based. Equal numbers of displayed examples do not represent
category frequencies. The figure shows Linear, MLP, CNN, GRU, and Transformer
predictions. LSTM is included in the aggregate and per-class comparisons;
its per-image prediction tensor is not available for this figure.

\subsection{Architecture trade-offs}
\label{sec:discussion}
CNN has the highest Fashion-MNIST test accuracy among the six measured models.
The comparison changes architecture, parameter count, and regularization
together, so it does not isolate which component explains the result.
Recorded training and inference durations use different hardware or timing
conditions. They do not support a speed ranking.

\subsection{Limitations}
Each configuration has one seed, and no systematic tuning study is reported.
Accuracy differences therefore do not estimate variability across training runs
or establish a general ranking of architecture families. Selected images
illustrate errors; they do not measure calibration.

\subsection{Conclusion}
Preserving spatial features with convolution and a hidden classification layer
works well in this Fashion-MNIST comparison. A controlled follow-up should vary
the spatial readout while holding training settings fixed and repeat the runs
across seeds.
