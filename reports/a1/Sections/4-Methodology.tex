\section{Methodology}
\label{sec:methods}

\subsection{Training and evaluation pipeline}
The study compares classifiers trained from scratch on MNIST, Fashion-MNIST,
and CIFAR-10. For each dataset, a seeded random permutation reserves 10\% of
its official training set for validation. The split is shared across models
and is not stratified. This gives 54,000 training and 6,000 validation images
for each grayscale dataset, and 45,000 training and 5,000 validation images for
CIFAR-10. Each official test set contains 10,000 images.

During training, minibatches pass through the encoder and a linear
classification head. Cross-entropy supplies the gradients for parameter
updates. Dropout and batch normalization use training mode. After each epoch,
the model is evaluated on the validation set with dropout disabled and batch
normalization using its running statistics. The checkpoint with the lowest
validation loss supplies the test predictions. The test set is excluded from
checkpoint selection.

\subsection{Model architectures}
\label{sec:architectures}
Each model maps an image to a feature vector $h\in\mathbb{R}^{d}$ and then
computes ten logits, $z=Wh+b$. The following descriptions use Fashion-MNIST
shapes. MNIST uses the same dimensions; CIFAR-10 supplies three-channel
$32\times32$ images. Table~\ref{tab:arch-comparison} summarizes feature
dimensions and parameter counts.

\subsubsection{Linear classifier}
The linear model flattens an image to $x\in\mathbb{R}^{784}$ and computes
$z=Wx+b$, where $W\in\mathbb{R}^{10\times784}$ and $b\in\mathbb{R}^{10}$.
Each class score is an affine function of the pixels. Flattening preserves
their fixed coordinate order; the model imposes no local connectivity or
spatial weight sharing. It provides the simplest baseline in the study.

\subsubsection{Multilayer perceptron}
The MLP applies two hidden affine layers of widths 256 and 128 to the flattened
image. Each hidden layer is followed by ReLU and dropout with probability
$0.2$. A linear head maps the 128-dimensional features to ten logits. The
nonlinear layers allow interactions between pixel values, while connections
remain fully connected without spatial weight sharing.

\label{fig:model-mlp}
\end{figure}

\subsubsection{Convolutional neural network}
The CNN retains the image grid and applies two convolutional blocks. Each
block contains a $3\times3$ convolution with stride 1 and padding 1, batch
normalization, ReLU, and $2\times2$ max pooling with stride 2. Convolution
biases are disabled. The channel widths are 32 and 64, giving block outputs
$32\times14\times14$ and $64\times7\times7$. Global average pooling reduces
the second output to 64 features for the linear head.

Convolution restricts each filter to a local neighbourhood and shares its
weights across spatial positions. Max pooling reduces spatial resolution;
global average pooling removes the explicit spatial coordinates from the final
feature vector. These choices define the model's spatial structure. Their
effect on classification errors is assessed in Section~\ref{sec:errors}.

\subsubsection{Gated recurrent unit}
The GRU reads the image rows from top to bottom. An input of shape
$C\times H\times W$ becomes a sequence of $H$ vectors in
$\mathbb{R}^{CW}$. Thus, Fashion-MNIST gives 28 steps with 28 values per step;
CIFAR-10 gives 32 steps with 96 values per step.

The model has one recurrent layer with hidden size 128 and initial state
$h_0=0$. Its updates are
\begin{align*}
 r_t &= \sigma(W_{ir}x_t+b_{ir}+W_{hr}h_{t-1}+b_{hr}),\\
 u_t &= \sigma(W_{iu}x_t+b_{iu}+W_{hu}h_{t-1}+b_{hu}),\\
 \widetilde h_t &= \tanh\!\left(W_{in}x_t+b_{in}
                 +r_t\odot(W_{hn}h_{t-1}+b_{hn})\right),\\
 h_t &= (1-u_t)\odot\widetilde h_t+u_t\odot h_{t-1}.
\end{align*}
Here, $\sigma$ is the sigmoid function and $\odot$ denotes elementwise
multiplication. The reset gate $r_t$ controls the recurrent contribution to
the candidate state; the update gate $u_t$ controls retention of the preceding
state. All steps share the same parameters. The final state $h_H$ supplies
the linear classifier. No recurrent dropout is used in the evaluated configuration.

\subsubsection{Long short-term memory}
The repository also implements a one-layer LSTM with hidden size 128, using
the same row sequence and a linear head on the final hidden state. In addition
to $h_t$, it maintains a cell state $c_t$. With zero initial states, the updates are
\begin{align*}
 q_t &= W_xx_t+b_x+W_hh_{t-1}+b_h,\\
 (i_t,f_t,g_t,o_t) &=
   \bigl(\sigma(q_{t,i}),\sigma(q_{t,f}),\tanh(q_{t,g}),\sigma(q_{t,o})\bigr),\\
 c_t &= f_t\odot c_{t-1}+i_t\odot g_t,\\
 h_t &= o_t\odot\tanh(c_t),
\end{align*}
where $q_t\in\mathbb{R}^{512}$ is divided into four 128-dimensional vectors.
The input, forget, and output gates control the cell update and hidden output.
The LSTM is trained and evaluated alongside the other five models on all
three datasets; its saved checkpoints supply the reported test predictions.

\subsubsection{Transformer}
The Transformer uses the same row tokens as the recurrent models. Each token
is projected to 128 dimensions and receives a sinusoidal positional encoding.
Embedding dropout has probability $0.1$. Two encoder layers each apply
four-head self-attention and a feed-forward network of widths
$128\to2048\to128$, with ReLU. Each sublayer uses a residual connection
followed by layer normalization; encoder dropout is $0.1$.

For a sequence representation $S\in\mathbb{R}^{H\times128}$, one attention
head computes
\begin{equation}
 Q=SW_Q,\quad K=SW_K,\quad V=SW_V,\qquad
 \operatorname{Attention}(Q,K,V)
 =\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{32}}\right)V,
\end{equation}
where $W_Q,W_K,W_V\in\mathbb{R}^{128\times32}$ and the softmax acts across
key positions. Projection biases are omitted from this notation. The four
head outputs are concatenated and projected to 128 dimensions. The mean of
the encoded row vectors supplies the linear classifier. Attention connects
all row positions, while positional encoding supplies their order.

\subsection{Loss and evaluation metrics}
\label{sec:metrics}

Let $\mathcal{D}=\{(x_i,y_i)\}_{i=1}^{N}$ denote a labelled sample, where
$y_i\in\{0,\ldots,K-1\}$ and $K=10$. For an input $x_i$, the model produces
a vector of logits $z_i=f_\theta(x_i)\in\mathbb{R}^{K}$. The corresponding
class probabilities and predicted label are
\begin{equation}
 p_{ik}=\frac{\exp(z_{ik})}{\sum_{j=0}^{K-1}\exp(z_{ij})},
 \qquad
 \hat y_i=\operatorname*{arg\,max}_{k}z_{ik}.
\end{equation}

\paragraph{Training objective.}
All models minimize the mean categorical cross-entropy,
\begin{equation}
 \mathcal{L}_{\mathrm{CE}}(\theta;\mathcal{D})
 =-\frac{1}{N}\sum_{i=1}^{N}\log p_{i,y_i}
 =\frac{1}{N}\sum_{i=1}^{N}
 \left[\log\sum_{k=0}^{K-1}\exp(z_{ik})-z_{i,y_i}\right].
\end{equation}
The implementation evaluates this loss directly from logits, without a preceding
softmax operation. Each optimization step uses the mean loss of its minibatch.
Epoch losses weight each minibatch by its sample count, so a smaller final batch
does not receive disproportionate weight. The checkpoint with the lowest
validation cross-entropy supplies the final test predictions. Test labels do not
enter this selection.

\paragraph{Classification performance.}
Define the confusion matrix $C$ by
\begin{equation}
 C_{ab}=\sum_{i=1}^{N}\mathbf{1}\{y_i=a,\ \hat y_i=b\},
\end{equation}
where rows correspond to true classes and columns to predicted classes.
Accuracy is the proportion of correct predictions,
\begin{equation}
 \mathrm{Accuracy}=\frac{1}{N}\sum_{k=0}^{K-1}C_{kk}.
\end{equation}
Accuracy summarizes overall classification performance but does not identify
which classes account for the errors.

For class $k$, let
$\mathrm{TP}_k=C_{kk}$,
$\mathrm{FP}_k=\sum_{a\ne k}C_{ak}$, and
$\mathrm{FN}_k=\sum_{b\ne k}C_{kb}$.
We report the unweighted mean of the class F1 scores,
\begin{equation}
 F_{1,k}=\frac{2\mathrm{TP}_k}
 {2\mathrm{TP}_k+\mathrm{FP}_k+\mathrm{FN}_k},
 \qquad
 \mathrm{Macro\text{-}F1}=\frac{1}{K}\sum_{k=0}^{K-1}F_{1,k}.
\end{equation}
A class with a zero denominator receives an F1 score of zero and remains in the
average. Macro-F1 gives every class equal weight, irrespective of its frequency.
We compute accuracy and macro-F1 from predictions over the complete evaluation
split, rather than averaging scores computed separately for each minibatch.

\paragraph{Class-level analysis.}
Per-class recall measures the fraction of examples of a true class that the
model identifies correctly,
\begin{equation}
 R_k=\frac{C_{kk}}{\sum_b C_{kb}}.
\end{equation}
For a class with nonzero support, the row-normalized confusion matrix is
$\widetilde C_{ab}=C_{ab}/\sum_j C_{aj}$.
Its diagonal entries equal class recall; its off-diagonal entries give the
fractions assigned to particular incorrect classes. Rows with no true examples
are displayed as zero and provide no estimate of recall. Counts and normalized
rates are distinguished throughout the error analysis.

\paragraph{Model size and computation.}
Model size is the number of trainable scalar parameters in the encoder and
classification head. This count excludes buffers and optimizer state. It measures
model size, not the number of operations required for a prediction. The evaluation
code also records the cumulative duration of model forward passes, excluding data
loading, input transfer, and subsequent probability and metric computation. These
single-pass measurements have no separate warm-up or repeated-trial protocol.
They are retained as execution records, not as evidence for a reliable speed
ranking across architectures.

\subsection{Training configuration}
\label{sec:training-setup}
\input{Tables/training_setup}
Training uses the dataset-specific transforms shared by all architectures.
For MNIST and Fashion-MNIST, pixel values are scaled to $[0,1]$, randomly
rotated within $[-10^\circ,10^\circ]$, translated by up to 10\% of each image
dimension, and normalized with mean and standard deviation $0.5$. CIFAR-10
uses a random $32\times32$ crop after four-pixel padding and a random horizontal
flip. Its channel means are $(0.4914,0.4822,0.4465)$ and standard deviations
$(0.2470,0.2435,0.2616)$. Validation and test transforms retain scaling and
normalization and omit random augmentation.

All current saved test evaluations record the NVIDIA GeForce RTX 4060 Laptop
GPU under Linux, Python 3.12.14, and PyTorch 2.14.0+cu126. Training logs record
CUDA execution; only the LSTM runs additionally preserve explicit GPU model
metadata. The single-pass timings do not establish a reliable speed ranking. Augmentation, dropout, and batch
normalization also make training and validation losses measurements under
different conditions.

\subsection{Comparison protocol}
\label{sec:experiment-design}
The experiment includes Linear, MLP, CNN, GRU, LSTM, and Transformer on all
three datasets, giving 18 runs of 50 epochs with seed 42. Fashion-MNIST is
the main comparison; MNIST development and CIFAR-10 extension results are
reported separately. Earlier five-epoch
Fashion-MNIST runs are preliminary and are excluded. The reported settings
specify one configuration per model; no systematic hyperparameter search or
component ablation is documented.

Within each dataset, models share the split, preprocessing, augmentation,
optimizer settings, epoch budget, and checkpoint rule. Model-specific
regularization and parameter counts remain unequal. Results describe the
observed configurations under one seed; repeated runs are required to assess
variation across initializations and training randomness.

For detailed Fashion-MNIST error analysis, the flattened-pixel baseline is
selected by the lower minimum validation loss among Linear and MLP, with a tie
resolved in favour of Linear. The selected baseline is compared with CNN on
the same official test images. Confusion matrices and class recall describe
all test predictions. Qualitative examples use the first two test indices in
each of three categories: CNN correct and baseline wrong, both wrong, and
baseline correct and CNN wrong. This rule fixes the examples independently
of visual appearance. Category frequencies are computed over the full test
set and reported separately from the selected images.
