\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}
We compare Linear, MLP, CNN, GRU, LSTM, and Transformer classifiers on
Fashion-MNIST to examine how image representation relates to accuracy and
classification errors. Each model trains for 50 epochs with seed 42, using the
same data split and preprocessing. Checkpoints minimize validation loss and
are evaluated on the official 10,000-image test set. CNN achieves the highest
accuracy, 92.59\%, and a macro-F1 of 0.9261. It exceeds the Transformer by
2.16 percentage points while using 421,738 parameters rather than 1,191,050.
Class recall and confusion matrices show that upper-body garments remain
frequent sources of error. CNN identifies 79.5\% of Shirt images, compared
with 62.1\% for MLP. Shared-image comparisons show that each model also
correctly classifies examples the other misses. The results support the CNN
configuration for this dataset, but do not establish a general ranking of
architecture families. Each configuration uses one seed, and architecture,
capacity, and regularization vary together. Recorded timings do not support
a speed comparison because hardware and measurement conditions differ.
