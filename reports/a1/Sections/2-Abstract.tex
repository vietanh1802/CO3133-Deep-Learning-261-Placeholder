\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}
We compare the accuracy and classification errors of Linear, MLP, CNN, GRU,
LSTM, and Transformer models on Fashion-MNIST. Each model trains for 50 epochs
with seed 42 on the same data split. We evaluate the checkpoint with the lowest
validation loss on the official 10,000-image test set. CNN achieves the highest
accuracy at 92.59\% and a macro-F1 of 0.9261. It exceeds Transformer accuracy
by 2.16 percentage points while using 421,738 parameters compared with
1,191,050. Confusions among upper-body garments account for 68.4\% of CNN
errors. CNN correctly identifies 79.5\% of Shirt images, compared with 62.1\%
for MLP. We also compare how the models classify the same images. Although
CNN has higher overall accuracy, MLP correctly classifies 234 images that CNN
misses. Each model uses one seed, so we cannot assess variation across training
runs. The runs also use different timing conditions, which prevents a speed
comparison.
