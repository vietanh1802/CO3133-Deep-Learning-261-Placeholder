\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}
This report studies ten-class Fashion-MNIST image classification using a shared
PyTorch pipeline. The required comparison covers a linear classifier, an MLP,
a self-designed CNN, a recurrent model (LSTM or GRU), and a Transformer.
Both LSTM and GRU are available in the repository, enabling an additional
comparison within the recurrent family. Models are assessed using predictive
quality, parameter count, training cost, inference cost, and qualitative evidence.
